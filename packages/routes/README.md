# Package: @rona/routes

This package contains all the route related data including path, request, response and notes.

## Rules

- Everything written here has to be constants, thereby written in UPPERCASE
- Prefix "CLIENT" and "API" will be used based on the apps they are located at.
- "API" prefix is followed by "ROUTE" suffix, and "CLIENT" followed by "PAGE"

(ESSENTIALs)

- For every api route entry, The should be a detail description like the request type, the request type, the response type (along with reference on where to find those types) and show multiple response types if they have varieties
